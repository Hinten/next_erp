# Review: Amazon's retired LATAM page "DBA caso de uso" vs the current global documentation

Provenance: read-only review dated 2026-10-14 for the Amazon SP-API marketplace integration (master plan `../amazon-marketplace-integration.md`). It compares one page of Amazon's former Latin America SP-API documentation site with the current global documentation (developer-docs.amazon) and the OpenAPI models (github.com/amzn/selling-partner-api-models). No live SP-API call was made. Facts about the legacy application's code are kept in the operator's private notes.

**Page:** `https://pt-br-group.readme.io/amazon-latam/docs/dba-caso-de-uso` (sibling: `.../docs/bem-vindo`).

**Status of the site.** The changelog entry "Update: Delivery by Amazon API documentation is now available on the global Selling Partner API website" says the DBA API documentation moved to the global site and that the Latin America site "will be removed on August 31, 2025". Only the DBA **invoice** documentation moved. On 2026-10-14 the page still loads, shows no last-updated date and no deprecation banner. Treat it as **retired but still served**: authoritative only where nothing official contradicts it.

**Why it matters.** It is the only Amazon page that describes **pickup scheduling and labels for Brazilian Easy Ship (DBA) orders**. The global Easy Ship API v2022-03-23 documentation lists no Brazil support, while the global `get-tax-information` page (Step 5) confirms that a BR Easy Ship pickup-scheduling step exists, gated on the invoice being `ACCEPTED`.

## What the plan takes from this page

- The BR scheduling call (#9, #10), the immediate download (#11), the resubmit recovery path (#12) and the scheduling gate (#8).
- Nothing from the outdated parts (#1, #2, #7): the plan uses `ORDER_CHANGE`, Orders v2026-01-01 and the Tax Invoicing role.
- Risk recorded in the plan: BR scheduling rests on a retired page plus production use; External Fulfillment Shipments v2024-09-11 is the documented alternative, with BR availability unknown.
