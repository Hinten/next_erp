# Code of Conduct

This project adopts the **Contributor Covenant 2.1** as its code of conduct.

The full text is available at: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Enforcement contact

Reports may be sent privately to the maintainers via the contact listed in `SECURITY.md` (same private channel). All reports will be handled in confidence.

## Why this file is short

The full Contributor Covenant text is preserved at the URL above. We reference it rather than mirror it so that the canonical version always reflects the latest version 2.1 errata.
